# GitHub Projects Bridge — Easypanel Template

[🇺🇸 English](README.md) | [🇧🇷 Português (Brasil)](README.pt-BR.md)

An Easypanel template for deploying [GitHub Projects Bridge](https://github.com/jaison/github-projects-bridge), a remote MCP server that manages GitHub Projects V2 through the GitHub GraphQL API.

This repository contains the template definition. It does not contain the MCP server implementation.

## What it creates

When the template is installed, it generates an Easypanel application that:

- Uses the `jaison/github-projects-bridge` repository, the `main` branch, and its root Dockerfile.
- Builds and runs the application on the internal port `3000`.
- Configures the service domain to route traffic to port `3000`.
- Enables automatic deployment from the configured GitHub source.
- Generates a unique `MCP_ACCESS_TOKEN` for the installation.

The access secret is generated using Node.js cryptographic random bytes (32 bytes / 256 bits), stored in the service environment, and retained across normal restarts and redeployments.

## Installation inputs

The template requests the following values:

| Field | Description |
| --- | --- |
| Service Name | Name assigned to the Easypanel application. Defaults to `github-projects-bridge`. |
| GitHub User or Organization | GitHub login that owns the Projects V2 to manage. |
| GitHub Fine-grained Personal Access Token | Token with the `Projects` permission set to **Read and write**. |

The template generates the MCP access secret automatically; you do not need to provide one.

## GitHub token permissions

Create a fine-grained Personal Access Token and grant the **Projects** repository/account permission required by your Projects V2 setup, with access set to **Read and write**.

The token is passed to the application as `GITHUB_TOKEN`. The selected owner is passed as `GITHUB_OWNER`.

## Generated environment

The application is configured with:

| Variable | Purpose |
| --- | --- |
| `GITHUB_TOKEN` | GitHub fine-grained Personal Access Token supplied during installation. |
| `MCP_ACCESS_TOKEN` | Random, per-installation secret generated by the template. |
| `GITHUB_OWNER` | GitHub user or organization that owns the projects. |
| `PORT` | Internal application port (`3000`). |

Keep both tokens private. In particular, clients connecting to the MCP endpoint must use the generated `MCP_ACCESS_TOKEN` as a Bearer token.

## Template files

- `meta.yaml`: template metadata, installation instructions, benefits, features, and input schema.
- `index.ts`: generates the Easypanel application configuration and per-installation access secret.

## Related project

## Publishing to the Easypanel public catalog

This repository keeps the template definition separate from the MCP server. To propose it for the official Easypanel catalog, copy `meta.yaml` and `index.ts` into `templates/github-projects-bridge/` in the `easypanel-io/templates` repository and submit a pull request.

The template follows the structure used by the catalog, but acceptance and publication are subject to review by the Easypanel maintainers.
